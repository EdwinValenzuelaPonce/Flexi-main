# FlexiWash – prototipo funcional

## Ejecutar
```bash
npm install
npm run dev
```

## Incluido en esta iteración
- Inicio de sesión por teléfono +52, correo y Facebook (flujo visual/demo).
- Inicio estilo delivery con dirección, búsqueda, notificaciones, carrito, promociones y solicitar de nuevo.
- Tres categorías principales: Autos, Hogar y Muebles.
- Productos extra.
- Personalización de auto por tipo de vehículo y cantidades por servicio.
- Cálculo de subtotal, domicilio, cuota de servicio y total.
- Métodos de pago: efectivo, tarjeta, PayPal y Monedero FlexiWash.
- Monedero con saldo, recarga demo y recompensa de 3%.
- Confirmación, seguimiento, historial, perfil, equipo y calificación.

## Pendiente para producción
Autenticación real, base de datos/API, geolocalización/mapas reales, pasarela de tarjeta/PayPal, SMS, panel de proveedor/admin, reglas de precios por tamaño y seguridad del backend.
